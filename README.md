# Forest Survey Data Extraction (OCR + OOPT)

Система автоматического извлечения данных из лесных актов. Процесс полностью автоматизирован: от скачивания архивов до формирования итоговой таблицы с проверкой зон ООПТ.

## Ключевой функционал

- **Полный цикл**: Скрипт сам находит гиперссылки на архивы в Excel, скачивает их, распаковывает и анализирует.
- **Интеллектуальный OCR**: Распознавание текста под углами 0°, 90°, -90° и обработка сложных случаев (зачеркивания, рукописные пометки).
- **Привязка к ООПТ**: Точное сопоставление по паре «Лесничество + Квартал» на основе официальных справочников.

## Требования

- **Python 3.10+**
- **Tesseract OCR** (пакет `rus`)
- **Poppler** (утилита `pdftoppm` должна быть в PATH)

## Инструкция по запуску (Полный цикл)

Для обработки нового файла (например, `Forest_200326.xlsx`), где в первой колонке («акт») содержатся гиперссылки, выполните одну команду:

```bash
python fill_oopt_excel.py --input "input_files/Forest_200326.xlsx" --output "results/Forest_200326.xlsx"
```

### Параметры:
- `--input` (`-i`): Путь к исходному Excel-файлу с гиперссылками в колонке «акт».
- `--output` (`-o`): Куда сохранить итоговый результат.
- `--oopt-dir`: (Опционально) Путь к папке со справочниками ООПТ, если она не в корне.

## Структура проекта

### 1. Основные скрипты
- **`fill_oopt_excel.py`** — **Главная точка входа.** Автоматизирует скачивание и запускает весь процесс.
- **`process_pdf.py`** — Движок распознавания (OCR). Содержит логику анализа текста PDF.
- **`oopt_registry.py`** — Модуль сопоставления координат с зонами ООПТ.

### 2. Папки
- `data/` — Сюда скрипт автоматически скачивает и распаковывает акты.
- `OOPT_territories/` — Справочники лесничеств (.doc/.txt).
- `input_files/` — Исходные списки для обработки.
- `results/` — Итоговые таблицы.

### 3. Вспомогательные файлы
- `download_data.py` — Модуль для работы с ZIP-архивами (используется автоматически, запускать отдельно не нужно).
- `setting.py` — Глобальные настройки путей.
